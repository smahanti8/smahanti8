## What's here

Every repo keeps a decision record (`DECISIONS.md`, or ADRs under `docs/`) — because architecture judgment is the job — and reports its own failures, because a pipeline that claims 100% is either being fed clean data or lying to you.

🏥 **[surgical-fhir-pipeline](https://github.com/smahanti8/surgical-fhir-pipeline)** — *shipped.* Maps synthetic robotic-surgery telemetry to FHIR R4B behind a FHIR REST API (a scoped $everything, CapabilityStatement, OperationOutcome errors; not a full FHIR server), and refuses to hide what the crossing destroys: 80% of cases exchangeable, every lossy mapping logged, terminology bindings marked `PROVISIONAL` with a test that fails if anyone promotes them without the work. Ships a Provenance resource per case and a SQLite-backed governance-KPI endpoint tracking exchangeability trends across runs. Its trust-status types are isolated in their own module; whether to share them with prior-auth-agent as a library was weighed and declined on the evidence ([D11](https://github.com/smahanti8/prior-auth-agent/blob/main/DECISIONS.md)). Interoperability as a governance problem, treated like one. [Live demo](https://smahanti8.github.io/surgical-fhir-pipeline/).

⚖️ **[prior-auth-agent](https://github.com/smahanti8/prior-auth-agent)** — *in progress.* A LangGraph agent drafting prior-authorization determinations: FHIR bundle + CPT → RAG policy retrieval → per-criterion evidence extraction → determination. One hard rule: it never drafts a denial (schema emits only approve / insufficient_evidence; humans make adverse calls). A bilateral citation gate rejects any “met” criterion missing both a policy quote and a FHIR citation. A deterministic confidence gate — not the model — decides auto vs. human review. Backed by policy-as-code criteria beside RAG, a hash-chained audit log, a 4-dimension golden eval suite with zero-cost cassette CI, and a Terraform PHI-boundary reference architecture (Fargate/KMS/S3 object-lock; documentation-grade, never applied). Per-node cost and latency telemetry feed a model-tiering analysis, and the audit packet reports a confidence-calibration metric (Brier score). It also exposes the policy corpus as a read-only MCP server (every response carries its citation), measures retrieval quality on its own (recall@k, MRR, gated separately from determination accuracy), and runs a four-case adversarial suite against chart-embedded instructions. [Live demo](https://smahanti8.github.io/prior-auth-agent/). Next: populate the eval baseline with a live run, calibrate the 0.85 threshold, fix vacuous auto-approve on empty criteria.

📡 **[fleet-anomaly-evals](https://github.com/smahanti8/fleet-anomaly-evals)** — *early.* An evaluation harness for anomaly detection on a simulated robot fleet, scored against labeled ground truth. Built so far: a seeded, physics-lite reference simulator, three fault injectors (motor thermal runaway, sensor drift, comms loss) and a fault ledger, with the key decision recorded as an ADR: ground truth is injection time, and when a fault became detectable is logged alongside it, so a detector's latency splits into signal-limited lag and algorithm lag. 65 tests. Not built yet: the bearing-wear injector (the wear curve is a deliberate open design decision), any detector, and the evaluation harness itself.

🧬 **[clinical-coding-lora](https://github.com/smahanti8/clinical-coding-lora)** — *early.* A QLoRA fine-tuning demonstration for ICD-10-CM coding on synthetic notes, built so every claim can be checked: a label set copied from a CMS file with its hash recorded, a test split that withholds two of six phrasing families from training, CPU baselines with bootstrap intervals, and an invalid-output rate kept apart from wrong-but-valid codes. Training and evaluation scripts are tested against a stub; the Phi-3-mini results are not run yet and will not be estimated.

🛡️ **regulated-ai-evals** — *next.* The trust layer extracted and generalized: requirement→prompt→test traceability, versioned golden sets, regression gates, auto-generated audit packets. What IEC 62304 taught me, expressed in pytest.

**Stack:** Python · Anthropic API (Opus, with a Haiku tiering analysis) · LangGraph · ChromaDB · MCP · FastAPI · FHIR R4B · GitHub Actions. No patient data in any repository. Clinical-style projects use synthetic data; other projects use public datasets, with the source and terms named in each README.
